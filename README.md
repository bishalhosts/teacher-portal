# Teacher Attendance Portal

A simple web app for teachers to mark daily student attendance.

---

## Files

- `index.html` — the app
- `manifest.json` — for installing on phone
- `icon-192.png`, `icon-512.png` — app icons

Keep all files in the same folder.

---

## How to Use

1. Open the app link shared by your school.
2. Enter today's **6-character code** from the teachers' group.
3. Select your **name** and **class**, then tap **Open class**.
4. Mark students **P** (present) or **A** (absent).
   - Use **All present** / **All absent** for quick entry.
5. Tap **Save** and confirm.

**Extra buttons:**
- **Copy absent** — copies the absent list for WhatsApp.
- **Logout** — clears the saved code.

---

## Notes

- The code changes every day at **6 AM**.
- Attendance can be edited the same day by saving again.
- Saturdays and listed holidays are closed automatically.
- Your name, class, and code are saved on your phone.

---

## Install on Phone

- **Android (Chrome):** Menu ⋮ → *Add to Home screen*
- **iPhone (Safari):** Share → *Add to Home Screen*

---

## Problems?

| Issue | Fix |
|-------|-----|
| Wrong/expired code | Get today's code from the group |
| Too many wrong attempts | Wait 10 minutes |
| "Not saved" | Check internet, tap Save again |
| Student missing | Contact your coordinator |

Contact your **school coordinator** for any other help.
